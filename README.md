# TAFA 校园网站与留言板

正式网站：https://ilovetafa.cn

## 网站文件

- `public/index.html`：网站页面。所有照片、样式、前端脚本都在 `public/`。
- `public/moderation.js`：指定词表及统一匹配规则，前端和后台共用。
- `api/[action].js`：Vercel 接口及实时推送。
- `lib/board.cjs`：数据库操作、后台词语检查。
- `scripts/schema.sql`：数据库结构及保证留言、点赞次数的原子操作。

Vercel 通过 `vercel.json` 发布 `public/`，数据库连接从 Vercel 环境变量读取。切勿提交 `.env` 文件或数据库连接密码。

## 留言规则

- 姓名和留言均按所给词表匹配。英文不区分大小写，全角字符统一处理，空格、标点、符号及零宽字符不能用来隔开禁用词。
- 采用严格的包含匹配，因此包含短词如 `ri`、`nc` 的较长英文内容也可能被拦截。需要放宽时可调整词表或规则。
- 发现禁用词显示警告，后台拒绝保存；拒绝的内容不消耗留言额度。
- 每个浏览器每天最多两条，按北京时间零点恢复。后台数据库加锁校验，重复请求使用提交标识去重。
- 每个浏览器对每条留言只能点赞一次，按赞数排序。
- 匿名身份保存在 Cookie；清除 Cookie 或换浏览器能获得新身份，不能等同于每个真人的严格身份验证。
- 查看留言板时建立实时连接，约每 3 秒检查并推送变化。离开留言板或把标签页放到后台会暂停连接。网络、数据库唤醒可能增加延迟。

## 云端运行

使用 Vercel 函数与 Neon 免费方案持久化数据库。关闭开发电脑不影响线上留言和点赞。免费方案有资源额度，超出额度时应查看 Vercel、Neon 控制台；本次没有开通付费方案。

数据库已通过 Vercel 集成连接到项目 `tafa` 的 production 和 preview 环境。测试部署也连接这一数据库，测试时不要改动真实访客的数据。

## 后续更新

修改 `public/` 中的页面或照片，将改动提交到 GitHub `main` 分支，Vercel 会自动部署。涉及接口时同时提交 `api/`、`lib/` 的改动。

新增词条：编辑 `public/moderation.js` 内的 `words` 数组后提交部署，前后端会一起使用新词表。

本源码包不包含数据库密码或访客留言备份。留言数据位于 Neon，重新部署网页不会清空留言。
